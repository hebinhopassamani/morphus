Pode ler com calma! Sobre a internet e o **Colorado (`colorado.morphus.me`)**, a notícia é **maravilhosa**: **NINGUÉM vai precisar digitar `:81` no navegador!** Vai ficar `https://colorado.morphus.me` limpinho e com cadeado HTTPS! 🔒

Você tem **2 caminhos perfeitos** para contornar a porta 80 presa pela operadora:

### Caminho 1: Usando o IP Fixo + NAT dessa internet de 600 Mb (Redirecionamento invisível na Cloudflare ou Porta 443)
Mesmo com a porta `80` bloqueada pela operadora:
1. **Todo site moderno roda na porta `443` (HTTPS)**, não na `80`! Se a `443` estiver livre no NAT, o usuário entra em `https://colorado.morphus.me` direto na `443`. (E para gerar o certificado SSL gratuito sem usar a porta 80, usamos validação por DNS — *DNS-01 Challenge* — que renova sozinho sem nunca tocar na porta 80).
2. **E se até a 443 você quiser mudar (ex.: abrir a porta `8443` ou `2053` no seu roteador)?**
   Se o domínio `morphus.me` estiver na **Cloudflare** (plano gratuito mesmo), existe um recurso chamado **Origin Rules**:
   - O usuário digita `https://colorado.morphus.me` normal (sem porta nenhuma);
   - A Cloudflare recebe na porta 80/443 dela e **redireciona por trás dos panos** para `SEU_IP_FIXO:8443` no seu roteador! O usuário nunca vê número de porta na URL.

### Caminho 2: Cloudflare Tunnel (`cloudflared` no Docker do Colorado) — *Zero portas abertas!*
Se você rodar o container oficial `cloudflared` no servidor Colorado:
- Ele cria uma conexão de **dentro do Colorado para fora** até a borda da Cloudflare.
- Você **não precisa abrir nenhuma porta no roteador** (nem 80, nem 443, nem 81) e **nem precisaria pagar os R$ 40 de IP fixo** se fosse só para web/HTTP (o IP fixo + NAT só continua sendo ótimo se você quiser acessar o Colorado via **SSH, VPN WireGuard ou Banco de Dados direto** de fora de casa!).
