2. Dentro de `"folders"`, adicione a propriedade `"name"`:
   ```json
   {
     "folders": [
       {
         "name": "Morphus",
         "path": "c:\\Projetos\\Morphus"
       }
     ]
   }
   ```
3. Se quiser que o título da janela também mude, basta usar **File > Save Workspace As...** e salvar como `Morphus.code-workspace`.
