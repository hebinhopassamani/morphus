### 🤖 Rafa *(Passo 356 — 2026-11-05T04:12:06Z)*
Funciona **100% no Angular Standalone sem precisar criar nenhum `NgModule`**!

O segredo do Angular moderno (Standalone) é que a propriedade `imports: [...]` do `@Component` aceita **arrays constantes (`as const`)** diretamente — o próprio compilador do Angular achata a lista em tempo de compilação.

Combinando isso com o `export *` no `index.ts`, você resolve **os dois problemas de uma vez só**:
1. Diminui as dezenas de linhas de `import { ... } from '@angular/material/...'` no topo do arquivo `.ts`;
2. Reduz o `imports: [...]` do `@Component` para **1 único item base** (`MorphusEditShared`, `MorphusListShared`, `MorphusNxNShared`) + apenas os componentes específicos daquela tela!

### Por que `IMorphusEditComponent` e `MorphusEditComponent` estavam juntos naquele `import`?

Porque em todo componente de edição existem **dois lugares diferentes** no arquivo `.ts` que precisam de imports:

1. **No `@Component({ imports: [...] })` (para o HTML)**:
   - Entra o `MorphusEditShared` (que agrupa `FormsModule`, `MatButton`, `MatFormField`, `MatInput`, `MatSelect`, `MatTab`, etc.).
2. **Na declaração da classe TypeScript (`extends ... implements ...`)**:
   ```ts
   export class CorporationEditComponent
     extends MorphusEditComponent<Corporation, CorporationValidator>
     implements IMorphusEditComponent, OnInit, OnDestroy
   ```
   - O TypeScript precisa da **classe pai** (`MorphusEditComponent`) para o `extends` e do **contrato/interface** (`IMorphusEditComponent`) para o `implements`, além do tipo `NgForm` no método `onSave(form?: NgForm)`.

Existe sim uma solução excelente para isso — é exatamente o padrão que ferramentas como **Auth0, GitHub, AWS e Supabase** usam para fugir dos dois extremos ruins (nem **cascata cega** que apaga tudo num clique por acidente, nem **bloqueio seco** que obriga você a peregrinar por 4 telas caçando filhos e netos).

A solução se chama **Exclusão Assistida com Resumo de Impacto (Confirmed Cascade Delete)**:

### Como funciona na prática:

1. **Se o Módulo (ou Submódulo) NÃO tiver vínculos**:
